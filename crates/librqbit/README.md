# librqbit

> **Fork note.** This is [zond/rqbit](https://github.com/zond/rqbit)'s librqbit, which consumers depend on by git rev. It has APIs that the crates.io release and docs.rs do not (see the [fork's README](../../README.md)); `cargo doc -p librqbit` builds its documentation.

A fully featured, easy to use torrent downloading library used as a backbone of [rqbit](https://github.com/ikatson/rqbit).
